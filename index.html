Dados pessoais identificáveis devem receber tratamento conforme a LGPD. O campo perfil da tabela usuario representa perfis previstos no modelo; a implementação de RBAC ainda depende de etapa posterior.

Data Literacy é a capacidade de compreender e utilizar dados de forma consciente. Este dicionário ajuda a equipe a interpretar os campos, manter a qualidade das informações e apoiar decisões consistentes.
